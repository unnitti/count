# 실수량 계산

박스 갯수와 박스 내 입수를 바탕으로 수량과 구간 합계를 계산하고, 정해진 형식으로 클립보드에 복사하는 웹앱입니다.

**[앱 실행하기](https://unnitti.github.io/count/)**

## 사용 방법

1. 입력창에 앱 안의 숫자 키패드로 수량을 입력합니다. **빈칸**과 **줄바꿈** 버튼으로 항목과 구간을 나눕니다.
2. **계산**을 눌러 줄별 계산 결과, 구간별 합계, 총 합계를 확인합니다.
3. 입력을 수정했다면 **계산**을 다시 누른 뒤 **클립보드에 복사**를 누릅니다.
4. 입력과 결과를 모두 비우려면 **전체 지움**을 누르고 확인합니다.

## 입력 및 계산 규칙

- 한 줄에 숫자 3개: `박스 × 입수 + 낱개`
- 한 줄에 숫자 2개: `박스 × 입수`
- 한 줄에 숫자 1개: 해당 숫자를 낱개 수량으로 그대로 사용
- 숫자는 공백, 쉼표, 마침표, `*`, `x`, `X`, `×`로 구분할 수 있습니다.
- 빈 줄마다 구간을 나눕니다. 각 구간의 유효한 줄 결과를 합산하고, 모든 구간 합계를 더해 총 합계를 계산합니다.
- 숫자가 없거나 4개 이상인 줄은 `입력 오류`로 표시하고 합산에서 제외합니다. 오류 줄도 복사 결과에는 포함됩니다.
- 복사 결과는 총 수량, 구간별 합계, 각 줄의 계산 내역 순서로 만들어집니다.

## 오프라인 사용 및 업데이트

- 처음에는 인터넷에 연결된 상태에서 앱을 열어 주세요. 앱 파일은 브라우저에 캐시되므로, 이후에는 인터넷 연결이 불안정하거나 끊긴 상황에서도 사용할 수 있습니다.
- 앱을 업데이트할 때는 인터넷에 연결한 상태에서 앱을 다시 열어 주세요. 새 버전의 파일을 내려받아 적용합니다.
- 앱 파일을 변경해 배포할 때는 `sw.js`의 캐시 버전도 함께 올려야 합니다. 버전이 바뀌면 새 파일을 캐시에 준비한 뒤 이전 캐시를 교체합니다.
- 브라우저의 웹사이트 데이터나 캐시를 삭제한 경우에는 인터넷에 연결해 앱을 다시 열어야 합니다.

## 지원 환경

iPhone Safari의 홈 화면에 추가한 웹앱을 기준으로 확인했습니다. Safari 탭, Android 및 다른 브라우저에서의 동작은 별도 확인이 필요합니다.

## 유지보수 메모

- 이 앱은 지정된 형식만 처리하는 도구입니다. 다른 형식은 결과에서 빠집니다.
- 기존 입출력 형식은 업무 흐름에 영향을 주므로 변경 전후에 실제 입력 예시로 확인합니다.
- 기능을 수정할 때는 온라인 실행, 오프라인 재실행, 주요 계산 및 복사 기능을 함께 점검합니다.
